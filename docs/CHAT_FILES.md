# 讨论室表情包与历史文件

## 当前行为

- 聊天输入栏提供「表情」和「发送图片」入口，已移除普通文件选择和上传。
- 表情面板可上传图片/GIF、发送收藏、移除收藏；长按其他人的图片/表情包可以添加到自己的收藏。GIF 保留动画。
- 图片和表情包仍使用原来的大小、帧数、收藏与发送频率限制。表情面板的图片/GIF文件导入属于表情上传，继续可用。
- 旧文件消息保留名称和大小，仍可下载保存到手机、举报或由发送者撤回；不迁移或删除已有文件数据。

## 后端接口

`POST /v1/rooms/{roomKey}/messages` 只接受文字、图片、表情包。旧客户端发送 `kind: file` 返回 HTTP 400、`code: FILE_UPLOAD_DISABLED` 和「文件上传功能已关闭。」，不创建消息或附件记录。

历史文件的 `GET /v1/messages/{id}/media` 继续验证 Bearer 身份，返回 `application/octet-stream`、`Content-Disposition: attachment` 和 UTF-8 文件名。其他用户不能代替发送者撤回，撤回删除附件字节并同步事件。

保留 messages.file_name、file_size 和历史 message_media 数据，无需重建数据库。图片/GIF最大请求体约13.34MiB+20,000字节，Nginx的15m限制继续用于表情包。

## 部署与验证

需要同步更新 app.py、chat.py、chat_files.py，并安装新客户端。部署前备份源码及数据库，部署后检查服务健康；回退恢复源码即可，数据库结构兼容。

回归覆盖旧客户端HTTP上传被拒绝且无新增附件、GIF发送下载、历史文件鉴权下载和撤回，以及客户端图片选择器、表情入口、历史文件保存与大字显示。
