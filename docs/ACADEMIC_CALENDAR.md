# SEU 2026—2027 学年校历（1.5.0+16）

资料来自用户提供的校历原图，并核对[东南大学教务处校历](https://jwc.seu.edu.cn/dndx2026w2027xnxl/list.htm)及[2026年节假日安排通知](https://jwc.seu.edu.cn/_upload/article/files/c3/32/c3b5a51f41ddab0e8f2e66069bf2/29abd5e8-e65f-492c-866e-0978dd0dc4f4.pdf)。日期使用上海日历日，手机改变时区不会改变放假或补课日期。

## 使用

「校园」新增「校历」，与劳动教育、教务通知并列。内置2026年8月到2027年8月月历、每天的校历事项、全年原图和官方来源入口，无需登录，月历与原图离线可看；打开学校官网才需要网络。

学期第一周周一与内置校历匹配时默认启用课表联动，不改写或删除原始课程。暑期学校匹配2026-08-24，秋季匹配2026-09-21，春季匹配2027-02-22。自定义学期日期不匹配时保持原课表；可在校历页选择学期，确认修改起点后启用联动。设置时保留已有课程、教师、地点、节次、单双周及额外安排，并保留覆盖现有课程周次所需的周数。

「我的 → 学期与作息 → 按 SEU 校历显示课程」可关闭联动，恢复原始每周排课。`Semester.useSchoolCalendar` 是v1备份的可选字段，旧备份缺失时默认开启；只对明确匹配的校历学期生效。读取、计算或升级不会写入课表文件；用户编辑或保存时才存储偏好。学校课程匹配继续使用原始课表，不把校历调整上传至讨论服务。

## 课表规则

| 日期 | 处理 |
| --- | --- |
| 2026-09-20 | 秋季开学，补2026-10-06（第3周周二）的课 |
| 2026-09-25—27 | 中秋放假，不调休 |
| 2026-10-01—07 | 国庆放假，不显示常规课 |
| 2026-10-10 | 补2026-10-07（第3周周三）的课，替代当天常规课 |
| 2026-11-05—07 | 校运会，停课不补 |
| 2027-01-11—24 | 秋季停课复习考试 |
| 2027-01-25—02-21 | 寒假 |
| 2027-02-22 | 春季学期第一教学周开始 |
| 2027-06-14—27 | 春季停课复习考试 |
| 2027-06-28—08-15 | 暑假 |

补课以被补日期的教学周、星期及单双周筛选原常规课程，保留教师、地点、节次与原课程标识；不复制明确日期的手动额外安排。9月20日在第1周周一之前，课表提供「开学补课周」显示，内部使用周0，不把第1周错移到9月14日。补课卡片显示「补·」，详情说明原日期与教学周。

即使原课表仅设置16周，周选择仍能查看校历的17、18周考试阶段；显示范围扩展不改写课程周次或学期周数。

根据用户选择，手动添加的实验、全天活动等在放假、校运会、考试和非教学期仍保留，标注「停课日额外安排」。课程冲突检查使用调整后的实际日期，包括开学前的补课。明确停课才隐藏常规课；注册、开学典礼、学位委员会会议、毕业手续等信息事项不取消课程。日期标签和「今天」展示对应校历说明。

2027年的法定节假日与调休未包含在本张校历中，本版本不推测相关日期。个人考试时间不从通用校历生成；老师单独通知的停课或补课也不自动推测。本版本内置规则，需要根据学校后续正式通知更新应用，未添加后台监控或实时校历抓取。

## 验证

模型回归覆盖中秋、国庆、校运会、期末、寒暑假、单双周来源周次、周0、周六原课替代、额外安排不复制、备份兼容、原数据不变、关闭联动、未匹配学期、跨时区与补课冲突。

界面回归覆盖无登录校园入口、月份切换与原图、学期切换确认/取消、课程及高周次额外安排保留、青梅/银杏补课详情、停课日「今天」不误报正在上课、小屏深色大字体月历。普通课表和Swift原版迁移测试显式关闭校历，继续验证原始课表计算；校历规则由独立测试验证。

不需要部署讨论室后端或修改学校登录。校历页面和核心排课使用Flutter共用代码；真机安装与视觉检查记录以PR说明为准。
