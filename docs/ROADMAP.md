# 梅课后续方向

以下是团队已提出的产品方向，用于讨论和拆分任务；它们不是当前版本已交付的功能，也不代表确定的发布时间。

## 当前基础：离线课表

Flutter 1.2.0 支持安卓 / iOS 共用代码、手动录入课程、多条常规安排、单双周、额外实验、整周课表、下课倒计时和 JSON 迁移。当前已完成 iOS 模拟器与真机验证，Android APK 构建和真机验证仍待完成。

## 第一阶段：跨平台课表与 SEU 信息入口

- 完成安卓构建、文件选择器和真机适配验证。
- 统一「梅课」品牌、图标、页面风格与版本管理。
- 完善课表导入；AI 识别结果先作为可编辑草稿，确认后再写入课表。
- 增加考试安排、校历和常用网址集合。先确定数据来源与更新时间，再实现自动同步。
- 加入课前提醒与课表小组件；分别评估 iOS 小组件 / 实时活动和安卓小组件 / 悬浮窗。

## 第二阶段：课程信息与协作

- 建立课程目录，并区分课程本身、某学期的开课班级和个人课表安排。
- 整合课程介绍、资料与课程相关信息，标明来源与适用学期。
- 加入课程讨论、评价和课程小组任务组队。
- 为多人功能增加账号、服务端存储、访问控制，以及举报 / 内容管理流程。
- 增加可选的跨设备同步，保持离线查看与编辑能力。

## 第三阶段：校级课表数据整合

- 明确各校区、教学楼、教室的统一标识，接入可用的课表和教室占用数据。
- 按教学周、单双周、考试和临时调整计算教室占用，展示当前或指定时间的空教室。
- 标明数据覆盖范围、最近更新时间和未知状态，避免把缺失数据直接当作空闲。
- 持续整合考试同步、学校通知与校历调整。

## 工程顺序

先把当前课表在两个平台稳定运行，再建立课程 / 开课班级 / 考试 / 教室的共享数据结构，随后接入后端和多人功能。每项新增能力都应说明需要的数据来源、平台集成和验证方式；原有备份迁移与本机离线课表继续保留。
