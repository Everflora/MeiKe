# 梅课 · 青梅与银杏

青梅 UI 已随 PR #6 合并；本次主题更新基于主分支 `b386c078f50d768a01c760e8636d606d8e478576`，继续保留课程组队、头像 PNG 兼容性修正、图片聊天与个人表情包收藏。

## 视觉规则

青梅使用暖白书页、深绿操作和银杏黄状态点。银杏严格采用已完成的「银杏书签」可点击预览：灰绿背景、深绿品牌页眉、独立圆角课表面板、面板内周次栏、素色课程卡与彩色左边书签、银杏黄当前课高亮、悬浮圆角导航。两套主题都保留梅花品牌标记、深绿状态卡和金色倒计时。下列颜色是梅课的设计提案，不作为学校官方 VI 色值。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |

`lib/ui/theme.dart` 统一文字、按钮、输入框、卡片、弹层和导航样式。课程保留原有 20 种颜色枚举，使用协调的柔和底色和对应的深色文字；青梅与银杏在浅色、深色下的课程及主要文字对比度至少为 4.5:1。梅花品牌标记和校园报刊图标由 CustomPainter 绘制，无外部字体或图标依赖。字标使用系统宋体回退，正文使用平台系统字体。

## 与已完成设计预览对应

原设计依据：`docs/design/meike-design-directions.html`（保留原可点击预览的源片段，依赖可视化宿主） 中的 `mk-book`（青梅书页）、`mk-garden`（银杏书签）。银杏的区分是布局，不是单纯换色：

- `mk-garden .mk-top` → `GinkgoHeader`：深绿页眉，梅花与「梅课」字标、MEIKE · SOUTHEAST，以及管理、导入、银杏黄添加键。状态栏白色，所有主页面共享页眉。
- `mk-garden .mk-calendar` / `.mk-week-strip` → 课表面板与独立周次栏：白色圆角面板、轻阴影、月份与日期、午晚休行、连续圆角今日列与当前时刻金线；银杏压缩短课间空隙，学校时段本身不变。
- `mk-garden .mk-course` / `.mk-current` → 素色描边课程卡、课程色左书签、当前课银杏黄背景；单节地点继续按宽度适配，可点击看完整信息。
- `mk-garden .mk-nav` → 独立悬浮圆角底栏；校园使用原预览的报刊轮廓图标，选中项保留金色圆点。
- 示例课程、固定日期、示例聊天室消息、示例身份与「课程与消息均为设计示例」提示只属于设计预览，不导入生产 App；实际课程、时间、消息与身份仍来自原有业务数据。

## 页面和入口

- 底部为「课表、今天、讨论、校园、我的」。课程管理从课表页右上角和「我的」进入，返回后仍停留在原来的页面和周次。
- 课表顶部只保留周次、翻周、管理、学校导入和添加。整周七天、13 节保持首屏优先；较矮屏幕或超出学校作息的额外安排可纵向滚动。课间时间仍在时间轴上显示，减轻背景分隔的重量。
- 今天突出当前状态与主题对应的下课倒计时，保留按实际节次计算下课时间和休息切换的逻辑。
- 点击课表 / 今日安排打开课程详情，完整显示名称、地点、时间、教师和备注，再进入原有课程编辑流程。课程地点优先整行显示；多节课空间不足时只在楼栋与房号的分隔符处换行，例如「教三-」/「304」，每行整体适配宽度，避免「教」单独成行。单节课及无分隔符地点保持完整一行，今天页采用同一组件。地点原文和无障碍朗读保持完整。
- 讨论课程列表、聊天气泡、校园栏目和教务通知卡片使用共同主题。组队、图片、表情包、撤回、举报、头像和课程匹配入口沿用最新版本。
- 「我的 → 外观」有两行独立设置：「主题」选择青梅 / 银杏，「显示模式」选择跟随系统 / 浅色 / 深色。切换主题不改变显示模式，反之亦然。
- 两项偏好独立于课表数据，仍保存在 `appearance.txt`，内容改为 JSON 的 `theme`、`mode`。可读取旧版本仅保存的 `system` / `light` / `dark`，保留显示模式并默认青梅；首次选择后写入新格式。未知主题回到青梅，未知显示模式回到跟随系统，损坏文件回到默认偏好。连续选择串行保存，不丢失任一偏好。外观不包含在 v1 课表备份中。

## 左上角品牌字标

按原设计预览参数固定：宋体粗体字标 21 px、字距 2 px；花形 20×20 px、描边 1.4/24、图标到文字间距 7 px；英文副标题 11 px、字距 1.6 px、行高 16.5 px。银杏页眉左侧留白 18 px，上下留白分别 7/14 px。

`brand_wordmark.dart` 保存原预览「梅课」两字的固定矢量轮廓，来自 STSongti-SC-Bold 的 21 px 字形；不打包系统字体文件，不依赖设备是否安装宋体。字标仍以「梅课」提供无障碍朗读。花形按原预览实际 Lucide Flower SVG 路径绘制，青梅和银杏保持相同品牌形状、比例，只使用各自的文字颜色。图标许可见 `docs/licenses/lucide.txt`。

## 教务栏目选择框

「校园 → 教务通知 → 教务处栏目」使用独立的主题绿色描边，普通与焦点状态均为 1.2 px、12 px 圆角。不要依赖点击后获得焦点来显示控件边界；首次进入和选择后失焦均应显示边框。回归测试覆盖青梅、银杏首次进入、切换栏目以及焦点移到搜索框。

## 维护约定

新页面使用 `context.meike` 和主题文字样式。`green` 字段延续旧命名，但实际代表当前主题的主操作色；状态卡使用 `hero` / `heroEnd` / `onHero` / `heroAccent`，不要写死绿色或白色。课程使用 `color.surface(context)` / `color.foreground(context)`，避免在深色界面直接使用浅色 pastel。主按钮用于保存或发送，次要操作使用浅底按钮，页面工具使用线性图标。

本次升级不修改课程模型、单双周、额外安排、学校解析、缓存格式或服务端协议。应用名称更新为「梅课」，Bundle ID / Android application ID 延续原值，版本为 `1.3.1+12`。

## 课表滑动切周

课表支持向左滑动到下一周、向右滑动到上一周，使用240毫秒平移动画，下一周从右侧进入、上一周从左侧进入。按钮和周次菜单继续可用，边界遵循学期显示范围（包括已联动秋季校历的周0），垂直滚动与课程详情入口保留。切换动画中的旧页面不接收点击或重复朗读。
