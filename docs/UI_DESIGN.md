# 梅课 · 青梅书页

本次 UI 基于主分支 `9113b3fd67d72055d05f7346cc2bde784bdcb79b`，包含课程组队、头像 PNG 兼容性修正、图片聊天与个人表情包收藏。

## 视觉规则

使用暖白书页、深绿操作和银杏黄状态点建立校园气质。下列颜色是梅课的设计提案，不作为学校官方 VI 色值。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F7F7F0` | `#111D17` |
| 卡片 | `#FFFFFF` | `#1B2B22` |
| 正文 | `#24382E` | `#EDF2E8` |
| 主要操作 | `#24543C` | `#B9D49E` |
| 状态点与倒计时 | `#D8BC60` | `#D8BC60` |

`lib/ui/theme.dart` 统一文字、按钮、输入框、卡片、弹层和导航样式。课程保留原有 20 种颜色枚举，使用协调的柔和底色和对应的深色文字；两种主题下课程文字与背景的对比度至少为 4.5:1。梅花标记以五瓣几何轮廓绘制，无外部字体或图标依赖。字标使用系统宋体回退，正文使用平台系统字体。

## 页面和入口

- 底部为「课表、今天、讨论、校园、我的」。课程管理从课表页右上角和「我的」进入，返回后仍停留在原来的页面和周次。
- 课表顶部只保留周次、翻周、管理、学校导入和添加。整周七天、13 节保持首屏优先；较矮屏幕或超出学校作息的额外安排可纵向滚动。课间时间仍在时间轴上显示，减轻背景分隔的重量。
- 今天突出当前状态与金色下课倒计时，保留按实际节次计算下课时间和休息切换的逻辑。
- 点击课表 / 今日安排打开课程详情，完整显示名称、地点、时间、教师和备注，再进入原有课程编辑流程。单节课格子中的地点按可用宽度适配。
- 讨论课程列表、聊天气泡、校园栏目和教务通知卡片使用共同主题。组队、图片、表情包、撤回、举报、头像和课程匹配入口沿用最新版本。
- 「我的 → 外观」可选择跟随系统、浅色、深色。设置独立保存在课表目录中的 `appearance.txt`，不写入 v1 课表备份；未知值或读取失败回到系统主题。

## 维护约定

新页面使用 `context.meike` 和主题文字样式。课程使用 `color.surface(context)` / `color.foreground(context)`，避免在深色界面直接使用浅色 pastel。主按钮用于保存或发送，次要操作使用浅底按钮，页面工具使用线性图标。

本次升级不修改课程模型、单双周、额外安排、学校解析、缓存格式或服务端协议。应用名称更新为「梅课」，Bundle ID / Android application ID 延续原值，版本为 `1.3.0+6`。
